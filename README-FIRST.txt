ROOT SEARCH IDENTITY FOR namcchet-cloud.github.io

WHY THIS EXISTS
Google Search chooses site name and favicon at the hostname/domain level. /CLB/ is a subdirectory, so metadata inside /CLB/ cannot reliably define a separate site name or search favicon.

HOW TO USE
1. Use this package ONLY if you are not already using the root hostname for another website.
2. Create a PUBLIC GitHub repository named exactly: namcchet-cloud.github.io
3. Upload the CONTENTS of this ZIP to the repository root.
4. In Settings > Pages, deploy from main / root if GitHub does not enable Pages automatically.
5. Confirm https://namcchet-cloud.github.io/ shows the small branded landing page and /CLB/ still works.
6. In Google Search Console, inspect BOTH https://namcchet-cloud.github.io/ and https://namcchet-cloud.github.io/CLB/ and request indexing.

This does not move, replace, or redirect the /CLB/ website. It only gives the hostname a real branded home page so Google has a valid source for site name + favicon.
