# CLB v7.3.3 — Startup & Cache Consistency

Base: `namcchet-cloud/CLB` main at `b7817412e9e6c96ecb9dc9f71e5be99287f280c7` (11/11/2026).

## Sửa lỗi / tối ưu
- Hiệu ứng intro giữ nguyên lần đầu mở tab. Reload hoặc điều hướng lại trong cùng phiên tab sẽ bỏ qua overlay để truy cập nhanh hơn. Không lưu lâu dài sang các phiên duyệt khác.
- Nếu tab đã ẩn trước khi ảnh intro tải xong, không khởi động animation nền vô ích.
- Cập nhật `data-build` của trang khi runtime được tải, tránh hiển thị nhãn 7.3.0 lỗi thời (HTML gốc chưa đổi).
- `js/app.js` import `build.js?v=7.3.3` và Service Worker cài sẵn đúng phiên bản module đó.
- Cache Service Worker nâng từ `clb-v7.3.2` lên `clb-v7.3.3`, giữ nguyên cơ chế cài đặt nguyên vẹn và fallback offline của v7.3.2.

## Giữ nguyên
- Không sửa CSS, layout, hình ảnh, font, nội dung, gallery, Raven hay điều khiển Spotify.
- Không thay đổi hoạt họa và thời lượng của intro *lần đầu* trong một phiên tab.
- Các URL script cũ trong HTML được giữ nguyên để giảm rủi ro thay đổi file 33 KB qua bản vá nhỏ; Service Worker v7.3.3 lấy mới nội dung các URL này khi cài đặt.

## Kiểm tra trước khi phát hành
1. `node --check sw.js`, `node --check js/features/intro.js`.
2. Mở web tab mới: intro vẫn chạy bình thường; reload cùng tab: intro được bỏ qua.
3. Mở tab mới độc lập: intro chạy lại; đặt chế độ motion Off: không có overlay.
4. Thử mở gallery, chọn album Spotify, đổi ngôn ngữ, Raven.
5. Khi có mạng, refresh trang 1-2 lần để service worker mới kích hoạt. Sau đó thử offline.
6. Kiểm tra footer Diagnostics hiển thị `v7.3.3`.

## Hạn chế
- Chưa có kiểm thử trên Safari iOS thực tế; `sessionStorage` có thể không khả dụng trong một số chế độ duyệt và sẽ fallback an toàn (intro lặp như cũ).
- `index.html` còn chuỗi `data-build=7.3.0` trong nguồn HTML; runtime đã đồng bộ sau khi JavaScript nạp, chưa sửa source HTML.
- Không thể xóa thư mục `site-files/` thừa bằng gói upload-only; hãy xóa riêng trên GitHub nếu cần.
