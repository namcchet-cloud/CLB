# v7.1.0: Playback stability and comic layout

## Fixed

- Re-enable Play/Pause immediately after matching Spotify playback confirmation.
- Keep the command watchdog alive when a late paused event arrives during Play.
- Re-enable the place/return control after the return animation finishes.
- Tear down native Spotify embeds on record return so hidden audio cannot continue.
- Ignore events from retired controllers and guard asynchronous session failures.
- Fall back to the native embed if a controller never emits ready within nine seconds.
- Prefer resume over play when continuing paused audio.
- Make the non-drag record placement control available on desktop and keyboard.
- Preserve pagination focus; eagerly load the image opened in the lightbox.
- Cancel pending artist effects on visibility/motion changes or lightbox opening.

## Visual Changes

- Place comic icons in section padding instead of hard-coded content positions.
- Keep smaller accents through tablet widths; hide the third accent on narrow screens.
- Add printed halftone, paper texture, and restrained offset section edges.
- Register decorated sections for viewport-controlled ambient animation.
- Suppress bursts and parallax in quiet mode, and pause decor in hidden tabs.
- Add record-placement feedback, busy feedback, accessible playback state, and larger controls.
- Allow deck controls to wrap without colliding; reserve space for button icons.

## Verification

Run with Node 22+ and Playwright installed locally:

```sh
npm install --no-save --package-lock=false playwright@1.51.1
npx playwright install chromium
node tests/browser.mjs
```

The runner hosts the site on a temporary local port and shuts down after testing.
It retains the site's CSP, blocks external requests, and simulates the documented
Spotify controller events. Screenshots are written to `/tmp/clb-qa`.

Coverage: command confirmation and timeout; actual motor angle changes; repeat
placement; stale controller events; readiness timeout; native embed removal;
gallery, language and keyboard focus; effect cancellation; decor collision and
horizontal overflow checks at 360, 390, 768 and 1280 pixels.
Pointer dragging and keyboard album replacement are also covered.

Transport reference: https://developer.spotify.com/documentation/embeds/references/iframe-api

## Remaining Live Checks

- Real Spotify playback, login/region restrictions, and autoplay behavior on iOS Safari.
- Full artist animations and artwork inspection on physical devices.
- Native fallback cannot report playback state to the deck; it deliberately does
  not pretend the record is spinning. The button reads Open player in this mode.
- This release does not replace the intro or rebuild the Raven animation.

All runtime asset query versions and the service worker cache are bumped together.
